# Project Name: Karlos Art Tattoo

## Context and Purpose
This project is a Single Page Application (SPA) with Server-Side Rendering (SSR) capabilities built as a premium, editorial-style landing page and portfolio for Karlos Art Tattoo. The goal is to showcase the artist's work (tatuagem autoral e fine line), list the locations they serve (Palhoça, Florianópolis, and Grande Florianópolis), and provide an integrated form to request bookings.

## Architecture Highlights
- **Framework**: TanStack Start & React 19
- **Routing**: @tanstack/react-router
- **Styling**: Tailwind CSS v4 + Radix UI Primitives (shadcn/ui style)
- **Animations**: Heavy use of GSAP for custom editorial animations and scroll interactions (via Lenis smooth scrolling).
- **Forms**: Formspree integrated within a custom React Hook Form for booking requests.
- **Data**: Static data for the portfolio, with links to Instagram.

## Target Audience
Clients seeking custom fine line tattoos in the Santa Catarina region (Brazil). The aesthetic is designed to feel high-end, premium, and exclusive.
