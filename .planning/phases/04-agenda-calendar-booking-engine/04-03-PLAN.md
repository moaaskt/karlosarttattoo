**Tipo:** expansão

**Fluxo de criação:**

- OU: botão "Bloquear Horário" no header da aba Agenda.

**Formulário:**

```
Tipo de bloqueio *
  ○ Horário específico   ● Dia(s) inteiro(s)

Data *                 Hora início    Hora fim
[date picker]          [09:00]        [18:00]
                    (oculto se "Dia(s) inteiro(s)")

Data início *         Data fim *
[date picker]         [date picker]
          (exibido apenas em "Dia(s) inteiro(s)")

Motivo *
[Viagem/Guest ▾]  (viagem_guest | folga_criacao | evento | pessoal | outro)
```

**Lógica:**

- `POST /api/time-blocks` → se 409 com `conflicts`: exibir modal de lista de conflitos com confirmação `force: true`.

**Exibição no calendário:**
- Time blocks aparecem com cor diferenciada (cinza escuro semi-opaco) e ícone 🚫.
- Ao clicar: drawer simplificado com motivo, datas e botão "Remover Bloqueio" (DELETE).

**Verificação:** Bloquear dia inteiro e horário específico funcionam; conflito com booking ativo exige confirmação; bloqueio aparece no calendário.

### TASK-14 — Backup Periódico do SQLite

**Tipo:** infraestrutura  
**Arquivo:** `src/lib/db-backup.ts` (novo, opcional/script)

Implementar backup simples via cópia do arquivo `data/leads.db`:

```ts
// Pode ser chamado manualmente ou via cron do sistema
import fs from 'node:fs';
import path from 'node:path';

export function backupDatabase(): void {
  const src  = path.resolve(process.cwd(), 'data/leads.db');
  const dest = path.resolve(process.cwd(), `data/backups/leads_${Date.now()}.db`);
  fs.mkdirSync(path.dirname(dest), { recursive: true });
  fs.copyFileSync(src, dest);
  // Manter apenas os últimos 7 backups
  const files = fs.readdirSync(path.dirname(dest))
    .filter(f => f.endsWith('.db'))
    .sort()
    .reverse();
  files.slice(7).forEach(f => fs.unlinkSync(path.join(path.dirname(dest), f)));
}
```

Adicionar script no `package.json`:
```json
"db:backup": "node -e \"require('./src/lib/db-backup.ts').backupDatabase()\""
```

**Verificação:** `npm run db:backup` cria arquivo em `data/backups/` e limpa os antigos além de 7.
