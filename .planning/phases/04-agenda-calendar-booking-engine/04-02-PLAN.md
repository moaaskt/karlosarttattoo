```ts
function bookingToEvent(b: Booking): EventInput {
  return {
    id: b.id,
    title: b.client_name,
    start: b.start_at,
    end: b.end_at,
    backgroundColor: statusColor(b.status),
    borderColor: depositStatusBorder(b.deposit_status),
    extendedProps: { booking: b },
  };
}

function statusColor(status: Booking['status']): string {
  return {
    pendente:   '#f59e0b',  // amber
    confirmado: '#9be5ff',  // neon cyan (brand)
    concluido:  '#22c55e',  // green
    cancelado:  '#6b7280',  // gray
    no_show:    '#ef4444',  // red
  }[status] ?? '#9be5ff';
}
```

**Lógica:**

- Presets de turno preenchem `hora início` com os valores de `settings` (`preset_manha`, etc.).

- Se a resposta contiver `warning: 'outside_hours'` E não tiver `force: true`, exibe modal de confirmação antes de reenviar.
- Se retornar 409 (conflito): exibe lista de conflitos com nomes e horários.

**Conversão de lead:**
- Ao receber `leadData` como prop (via "Agendar Sessão" na aba de leads): pré-preenche nome, telefone, email e `lead_id`.

### TASK-10 — Drag & Drop para Remarcação (FullCalendar Interaction)

**Tipo:** expansão  
**Arquivo:** `src/components/admin/agenda-tab.tsx`

**Callback `eventDrop`:**

```ts
async function handleReschedule(event: EventApi, revert: () => void) {
  const id = event.id;
  const newStart = event.startStr; // já é ISO UTC do FullCalendar
  const newEnd   = event.endStr;

  const res = await fetch(`/api/bookings/${id}/reschedule`, {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ start_at: newStart, end_at: newEnd }),
  });

  if (!res.ok) {
    const body = await res.json();
    revert(); // cancela o drag visualmente
    toast.error(`Conflito: ${body.conflicts?.map(c => c.client_name).join(', ')}`);
    return;
  }

  // Se tiver warning outside_hours (caso suportado no futuro), mostrar toast info
  toast.success('Agendamento remarcado');
  // Refetch do calendário
}
```

**Restrições:**
- Bookings com `status = 'cancelado' | 'no_show' | 'concluido'` não são draggable (`editable: false` por evento).
- Drop fora do intervalo de expediente mostra toast de aviso mas não bloqueia (o backend decide).

**Verificação:** Arrastar booking para slot livre → persiste; arrastar para slot ocupado → revert + toast de erro.
