## Fatos do Backend (db.ts) — lidos antes de planejar

### AvailabilityRule (campos reais)
```ts
interface AvailabilityRule {
  id: string;
  day_of_week: number;   // 0=Dom … 6=Sáb
  window_start: string;  // "09:00"
  window_end:   string;  // "20:00"
  is_active:    number;  // 1 = ativa, 0 = inativa
}
```
**Seed padrão:** Ter-Sex (09:00-12:30 e 14:00-20:00), Sáb (09:00-14:00). Múltiplas janelas por dia.

### Settings (chaves reais)
| Chave | Default |
|-------|---------|
| `timezone` | `America/Sao_Paulo` |
| `buffer_minutes` | `30` |
| `preset_manha` | `09:00` |
| `preset_tarde` | `14:00` |
| `preset_noite` | `18:30` |

**Não existem** `slot_min_time` / `slot_max_time` no banco.

### rescheduleBooking — respostas reais
| Condição | HTTP | Body |
|----------|------|------|
| outside_hours + `force=false` | 409 | `{ warning: "outside_hours", message }` (sem booking) |
| time_block_conflict | 409 | `{ error: "time_block_conflict", conflicts, message }` |
| booking_conflict | 409 | `{ error: "booking_conflict", conflicts, message }` |
| invalid_status | 422 | `{ error: "invalid_status", message }` |
| Sucesso com warning | 200 | `{ success: true, booking, warning: "outside_hours" }` |
| Sucesso normal | 200 | `{ success: true, booking }` |

**`force` é aceito** por `rescheduleBooking` e está no schema Zod da rota.

### updateBookingStatus — invariantes reais
- Terminais (`cancelado`, `no_show`, `concluido`): nenhuma transição permitida.
- `confirmado → pendente`: recusado explicitamente (linha 939-948 do db.ts).
- `cancelado/no_show` com `deposit_status = "pago"`: exige `depositAction`.
- `retido`/`devolvido`: só válidos em `cancelado` ou `no_show` (verificado no `updateDepositStatus`).

### getBookingById — retorna events
```ts
getBookingById(id) → Booking & { events: BookingEvent[] } | null
```
GET `/api/bookings/:id` retorna `{ success, booking: { ...booking, events: [...] } }`.

## Decisões de Arquitetura

### D-A: Timezone com `@fullcalendar/luxon3`
`@fullcalendar/luxon3` e `luxon` instalados. A `timeZone` vem de `settings["timezone"]` (default `"America/Sao_Paulo"`). O modal usa `luxon.DateTime` para converter data+hora local → UTC antes de enviar à API.

### D-B: Padrão client-only (idêntico ao `ApexChartClient`)
**Sem** `next/dynamic` nem `'use client'`. `React.useState + React.useEffect + import()` dinâmico. Referência: `src/components/admin/apex-chart-client.tsx`.

### D-C: Helper `apiFetch` único
`src/lib/api-client.ts` — único ponto de fetch autenticado. Lê `sessionStorage.getItem("admin_auth_token")`. Retorna `{ ok, status, data }`. **Se 401**: limpa sessão (`sessionStorage.removeItem`) e dispara `window.dispatchEvent(new CustomEvent("admin:logout"))`. Nenhum `fetch` inline nos componentes de agenda.

### D-D: Serialização de datas
**Nunca** usar `startStr`/`endStr` do FullCalendar na API. Sempre `event.start.toISOString()` / `event.end.toISOString()` (produz `...sss.Z`). Para `datesSet`: `info.start.toISOString()` (Date object). `startStr` só pode ser usado para extrair `YYYY-MM-DD` para o picker (`.slice(0,10)`).

### D-E: Time blocks como `display: 'background'`
Time blocks → `display: "background"`, `editable: false`. All-day time blocks ficam na faixa superior. Select sobre fundo de time block: **UX opcional** — o backend é a autoridade (retorna 409 time_block_conflict se tentado). Não bloquear via `selectConstraint` para evitar complexidade de sobreposição; confiar no backend.

### D-F: Tela de Configurações (⚙)
Fica no **Plano 04-03**.

### D-G: `eventResize` → mesmo fluxo de `eventDrop`
Mesma função `handleReschedule`. Se o FullCalendar não expuser `eventResizeDoneArg.revert()` de forma utilizável, desabilitar `eventDurationEditable`.

### D-H: `businessHours` e `slotMinTime/Max`
- `businessHours`: filtrar `is_active === 1`, usar `window_start/window_end`. Múltiplas entradas por `day_of_week`.
- `slotMinTime`: menor `window_start` das regras ativas menos 1h (nunca abaixo de `"00:00:00"`).
- `slotMaxTime`: maior `window_end` das regras ativas mais 1h (nunca acima de `"24:00:00"`).
- Derivar em runtime no frontend com função pura testável.

### D-I: Fim <= início no modal (virada de meia-noite)
Se `endTime <= startTime` (ex: noite 18:30 + 6h = 00:30), somar 1 dia à data de fim e exibir badge "termina no dia seguinte". `localToUTC` recebe `endDate` separado de `startDate`.

### D-J: Toast/diálogo do projeto
Substituir `alert()`/`window.confirm()` por componente de toast/diálogo existente no projeto (verificar `sonner` ou equivalente no `package.json` antes de implementar; se não existir, usar `sonner` via `npm install`).

### D-K: Execução em duas ondas
- **Onda A** (backend + fundação): TASK-05b → TASK-07 → TASK-06 → TASK-08 (calendário read-only com eventos). Para e aguarda checkpoint.
- **Onda B** (UI interativa): TASK-09 → TASK-10 → TASK-11.

```ts
/** Serializa Date → ISO UTC estrito (...sss.Z) */
export function toUTCString(date: Date): string {
  return date.toISOString();

/** Centavos → "R$ X,XX" (sem float) */
export function centsToDisplay(cents: number): string {
  return "R$ " + (cents / 100).toFixed(2).replace(".", ",");
}

/** "X,XX" ou "X.XX" ou "1.500,00" → centavos inteiros (Math.round) */
export function displayToCents(value: string): number {
  // 1. Normalizar separador de milhar / decimal
  const normalized = value
    .replace(/\s/g, "")
    .replace(/^R\$\s?/, "")
    .replace(/\./g, "")   // remove pontos de milhar
    .replace(",", ".");   // vírgula decimal → ponto
  const n = parseFloat(normalized);
  if (isNaN(n)) throw new Error(`Valor inválido para conversão: "${value}"`);
  return Math.round(n * 100);
}

/** Apenas dígitos; se começar com +55 não duplica o DDI */
export function formatWhatsAppPhone(phone: string): string {
  const digits = phone.replace(/\D/g, "");
  if (digits.startsWith("55") && digits.length > 11) return digits; // já tem DDI
  return digits;
}

/** Converte ISO UTC → { date: "YYYY-MM-DD", time: "HH:MM" } no fuso tz */
export function utcToLocal(iso: string, tz: string): { date: string; time: string } {
  const { DateTime } = require("luxon"); // dynamic para não quebrar SSR
  const dt = DateTime.fromISO(iso, { zone: "utc" }).setZone(tz);
  return {
    date: dt.toFormat("yyyy-MM-dd"),
    time: dt.toFormat("HH:mm"),

}

/** Fetch autenticado — único ponto de acesso à API da agenda */
export async function apiFetch<T = unknown>(
  path: string,
  options?: RequestInit
): Promise<{ ok: boolean; status: number; data: T }> {
  const token =
    typeof window !== "undefined"
      ? sessionStorage.getItem("admin_auth_token") ?? ""
      : "";
  const res = await fetch(path, {
    ...options,
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${token}`,
      ...(options?.headers ?? {}),
    },
  });
  if (res.status === 401) {
    if (typeof window !== "undefined") {
      sessionStorage.removeItem("admin_auth_token");
      window.dispatchEvent(new CustomEvent("admin:logout"));
    }
  }
  const data = await res.json().catch(() => ({}));
  return { ok: res.ok, status: res.status, data: data as T };
}
```

```ts
async function handleDatesSet(info: DatesSetArg) {
  // info.start e info.end são Date objects — NUNCA usar startStr/endStr
  const from = toUTCString(info.start);
  const to   = toUTCString(info.end);
  currentRangeRef.current = { from, to };
  await refreshBookings(from, to);
}

async function refreshBookings(from?: string, to?: string) {
  const range = from && to ? { from, to } : currentRangeRef.current;
  if (!range) return;
  const [rb, rt] = await Promise.all([
    apiFetch<{ bookings: Booking[] }>(`/api/bookings?from=${range.from}&to=${range.to}`),
    apiFetch<{ timeBlocks: TimeBlock[] }>(`/api/time-blocks?from=${range.from}&to=${range.to}`),
  ]);
  if (rb.ok) setBookings(rb.data.bookings);
  if (rt.ok) setTimeBlocks(rt.data.timeBlocks);
}
```

```ts
async function handleReschedule(info: EventDropArg | EventResizeDoneArg) {
  const id = info.event.id;
  // NUNCA usar startStr/endStr — usar .start/.end (Date)
  const newStart = toUTCString(info.event.start!);
  const newEnd   = toUTCString(info.event.end!);

  const result = await apiFetch<any>(`/api/bookings/${id}/reschedule`, {
    method: "PATCH",
    body: JSON.stringify({ start_at: newStart, end_at: newEnd }),
  });

  if (!result.ok) {
    info.revert();
    const err = result.data;
    // outside_hours retorna 409 com { warning: "outside_hours", message } (sem booking)
    if (err.warning === "outside_hours") {
      showConfirmDialog(
        getErrorMessage("outside_hours") + "\nDeseja confirmar mesmo assim?",
        async () => {
          const forced = await apiFetch<any>(`/api/bookings/${id}/reschedule`, {
            method: "PATCH",
            body: JSON.stringify({ start_at: newStart, end_at: newEnd, force: true }),
          });
          if (forced.ok) await refreshBookings();
          else showToast("error", getErrorMessage(forced.data?.error));
        }
      );
      return;
    }
    const conflicts = (err.conflicts ?? []) as Array<{ client_name: string }>;
    showToast("error",
      getErrorMessage(err.error) +
      (conflicts.length ? ` (${conflicts.map(c => c.client_name).join(", ")})` : "")
    );
    return;
  }

  if (result.data.warning === "outside_hours") {
    showToast("info", "Remarcado fora do expediente.");
  }
  await refreshBookings();
}
```
