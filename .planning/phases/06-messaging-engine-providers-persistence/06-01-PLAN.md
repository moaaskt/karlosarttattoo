## 🎯 Objetivo da Fase 06

Implementar a base completa do módulo de mensageria automatizada do Karlos Art Tattoo:
1. Módulos puros de tipagem (`types.ts`) e motor de interpolação de variáveis (`engine.ts`) com templates padrão integrados.
2. Conectores de envio para **WhatsApp via Evolution API v2** e **E-mail via SMTP** em `messaging-service.ts`.
3. Persistência relacional em SQLite WAL com tabelas `message_templates`, `message_logs`, `messaging_settings` e funções de acesso em `src/lib/db.ts`.
4. Endpoints de API REST em `src/server/api/messages.ts` protegidos por autorização administrativa e despachados em `src/server.ts`.
5. Suíte de testes unitários automatizados validando interpolação, sanitização de telefones, CRUD de templates e envio.

### TASK-02 — Motor de Interpolação & Templates Padrão (`src/lib/messaging/engine.ts`)
- **Tipo:** Lógica de Negócio Pura
- **Arquivos:** `src/lib/messaging/engine.ts`
- **O que fazer:**
  1. Criar função pura `interpolateTemplate(template: string, data: Record<string, any>): string`:
     - Substitui tags no formato `{{variavel}}` ou `{{ variavel }}` (insensível a maiúsculas/minúsculas).
     - Mapeia variáveis comuns do estúdio:
       - `{{nome}}`: Nome do cliente
       - `{{telefone}}`: Telefone de contato
       - `{{email}}`: E-mail
       - `{{ideia}}`: Descrição da tatuagem / projeto
       - `{{local}}`: Modalidade ou local de atendimento
       - `{{estilo}}`: Estilo desejado
       - `{{data_agendamento}}`: Data formatada (ex: `15/10/2026`)
       - `{{horario_agendamento}}`: Horário formatado (ex: `14:00`)
       - `{{valor_total}}`: Preço total em reais (ex: `R$ 800,00`)
       - `{{valor_sinal}}`: Valor do sinal / depósito (ex: `R$ 200,00`)
       - `{{chave_pix}}`: Chave PIX do ateliê
  2. Criar função `extractVariablesFromTemplate(body: string): string[]`:
     - Retorna lista de variáveis únicas encontradas no texto.
  3. Definir e exportar lista de templates padrão de fábrica (`DEFAULT_TEMPLATES`):
     - **Boas-vindas (WhatsApp):** Agradecimento pelo contato, confirmação de recebimento da ideia e proposta de alinhamento.
     - **Cobrança de Sinal / Reserva (WhatsApp):** Confirmação de disponibilidade com instruções e chave PIX para reserva de data.
     - **Confirmação de Agendamento (WhatsApp & E-mail):** Dados completos da sessão (data, horário, endereço do estúdio em Palhoça).
     - **Lembrete 24h Antes (WhatsApp):** Instruções pré-sessão (boa noite de sono, hidratação, alimentação).
     - **Cuidados Pós-Tattoo (WhatsApp & E-mail):** Guia com orientações de cicatrização (lavagem com sabonete neutro, pomada, proteção solar).
     - **Promoção Flash Day / Campanha (WhatsApp):** Mensagem de convite para eventos e flashes autorais.

### TASK-03 — Conectores Multi-Canal (`src/server/lib/messaging-service.ts`)
- **Tipo:** Serviços de Integração REST & SMTP
- **Arquivos:** `src/server/lib/messaging-service.ts`
- **O que fazer:**
  1. Implementar sanitizador de telefone `sanitizeWhatsAppNumber(phone: string): string`:
     - Remove caracteres especiais e espaços.
     - Remove 0 inicial do DDD.
     - Garante prefixo internacional `55` sem duplicações.
  2. Implementar `sendWhatsAppMessage(params: { recipient: string; message: string; config?: MessagingConfig }): Promise<{ success: boolean; messageId?: string; error?: string }>`:
     - Endpoint Evolution API v2: `POST {evolutionUrl}/message/sendText/{instanceName}`
     - Headers: `{ apikey: evolutionApiKey, 'Content-Type': 'application/json' }`
     - Body: `{ number: formattedPhone, text: message }`
     - Validação defensiva de status HTTP e retorno com detalhes.
  3. Implementar `sendEmailMessage(params: { recipient: string; subject: string; body: string; config?: MessagingConfig }): Promise<{ success: boolean; messageId?: string; error?: string }>`:
     - Conexão SMTP via `nodemailer.createTransport`.
     - Envio de e-mail em formato HTML + texto plano.
  4. Implementar funções de teste de conectividade:
     - `testEvolutionConnection(config: MessagingConfig): Promise<{ connected: boolean; details?: string }>`:
       - Consulta `GET {evolutionUrl}/instance/connectionState/{instanceName}`
     - `testSmtpConnection(config: MessagingConfig): Promise<{ connected: boolean; details?: string }>`:
       - Executa `transporter.verify()`

### TASK-05 — Rotas de API Backend (`src/server/api/messages.ts` e `src/server.ts`)
- **Tipo:** API REST & Roteamento
- **Arquivos:** `src/server/api/messages.ts`, `src/server.ts`
- **O que fazer:**
  1. Criar `src/server/api/messages.ts`:
     - Validação de autorização com `isAuthorized(request)`.
     - `GET /api/messages/templates`: Lista templates cadastrados.
     - `POST /api/messages/templates`: Criação com validação Zod.
     - `PATCH /api/messages/templates/:id`: Atualização com validação Zod.
     - `DELETE /api/messages/templates/:id`: Remoção lógica ou física.
     - `POST /api/messages/send`:
       - Recebe destinatário, canal, mensagem (ou template_id + dados do lead para interpolação).
       - Despacha para `sendWhatsAppMessage` ou `sendEmailMessage`.
       - Grava registro na tabela `message_logs`.
       - Retorna status do envio.
     - `POST /api/messages/test-connection`: Testa WhatsApp ou SMTP.
     - `GET /api/messages/logs`: Retorna histórico recente de mensagens.
     - `GET /api/messages/config` & `PATCH /api/messages/config`: Gerencia credenciais.
  2. Integrar no despachante principal `src/server.ts`:
     ```ts
     if (url.pathname === "/api/messages" || url.pathname.startsWith("/api/messages/")) {
       return await handleMessagesRequest(request);
     }
     ```
