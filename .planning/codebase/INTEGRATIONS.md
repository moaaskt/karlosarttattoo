# Integrations

## External Services

- **Formspree**: Used for handling the booking form submissions in `src/components/booking-modal.tsx`. The endpoint used is `https://formspree.io/f/xqpkwdzp`.
- **Instagram**: External links directing users to the Instagram page (`https://www.instagram.com/karlitostattooo/`) are prominently featured in the header and portfolio section.

## Internal APIs / Data

- **Portfolio Data**: Currently hardcoded in `src/data/portfolio.ts` (implied by the import in `src/routes/index.tsx`). It contains the list of tattoo images, captions, types, and instagram URLs to display in the grid.
